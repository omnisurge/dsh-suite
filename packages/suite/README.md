# 万物生腾套件组（Omnisurge Suite）

面向官方 the agent harness 的扩展套件。版本以随包 package.json 为准。本批包括摘要预算、状态投影与可选设置；验证范围及结果以对应版本的验收记录为准，历史版本结果不替代本包验收。

本批验证目标为 the agent harness 0.2.2-rc.5 / macOS；0.3.6 稳定版已完成精确候选门禁与隔离 G5，最终发行包以该版本绑定的验收记录为准。Windows、Linux 未作本代 G6 验证；OCR（腾讯云/百度）与文档解析（MinerU/PaddleOCR）的真实供应商效果和原生 G5 也未作本代验证。逐项状态见[支持矩阵](../../docs/guides/support-matrix.md)，不要把代码存在或自动门禁通过当作已验。单大尾节点的压力限制仍未解决；界面自然达到零会话等待状态仍未亲验，其余完整名单、配置与生命周期按本批范围验证，例外及后续条件以验收记录为准。

它把常用的多模态与协作能力放进设置页，安装一次即可按需启用：

- 联网搜索（SearXNG）
- 手写识别
- 文档解析
- Agent Teams 与环境
- MCP 登录网关
- 压缩摘要预算（可选，默认关闭）；旧压缩守卫已退役

## 安装

1. 通过官方插件管理安装本地 Suite tgz。
2. 打开 **Plugins → 万物生腾套件组**。
3. 打开需要的业务行或能力开关；首次安装时业务行默认关闭。
4. 配置需要的供应商凭据，保存后执行「测试」确认连通。
5. 有新版本时，从套件更新卡升级；需要加载新字节时按提示重启应用。

## 能做什么

| 能力 | 用途 | 使用入口 |
|---|---|---|
| 联网搜索（SearXNG） | 给对话接入自建 SearXNG 搜索后端 | 业务行或套件页的联网搜索设置 |
| 手写识别 | 识别图片或页面中的印刷体、手写文字 | 设置页「手写识别」卡 |
| 文档解析 | 把 PDF、图片或办公文档解析成 Markdown、JSON 或可下载结果 | 设置页「文档解析」卡 |
| Agent Teams 与环境 | 团队协作配置、环境笔记与极限模式 | 设置页「Agent Teams 与环境」 |
| MCP 登录网关 | 为需要 OAuth 的 MCP 服务提供登录入口 | MCP 设置中的登录操作 |
| 压缩摘要预算 | 为官方摘要追加正文预算并校验容量与输出；不阻断压缩入口 | 官方插件行 `omnisurge-compaction-budget`（默认关闭） |

## 联网搜索

- 支持自定义 SearXNG 地址、引擎组和基础认证引用。
- 保存后先执行「检查配置状态」，确认后端可达。
- 本套件不会因为配置了后端就自动把全局搜索切换到该 provider；是否使用由你的搜索设置决定。

## 手写识别

- 支持腾讯云和百度智能云 OCR。
- 默认关闭。开启后，识别会把页面发到所选供应商，并消耗其额度。
- 「测试状态」会使用最近一张对话图片，消耗一次测试额度。
- 可设置单次页数上限，避免一次发送过多页面。

## 文档解析

- **MinerU Agent**：免 Token，单文件最多 10 MB / 20 页，输出 Markdown；适合快速预览。
- **MinerU API 精准**：需要 API Key，支持更大文件、表格、公式和多格式结果。
- **PaddleOCR**：需要 Token，支持多种异步解析模式。
- 文档解析与手写识别是两项独立能力，不会因为其中一项失败而自动切换供应商。
- 「测试状态」使用公开示例 PDF；供应商排队或不可用时，界面会显示对应错误，而不是伪装成成功。

## Agent Teams 与环境

- 管理团队协作配置和环境笔记。
- 极限模式会按当前会话使用的模型决定是否注入提示词；模型判断优先使用官方运行时的模型信息，必要时回退到会话状态。

## MCP 登录网关

- 对需要 OAuth 的 MCP 服务，在官方 MCP 设置中发起登录，完成授权后连接。
- 登录状态和凭据由官方凭据服务管理；套件只保存引用。

## 压缩摘要预算（可选，默认关闭）

- 旧 `omnisurge-compaction-guard` 入口已退役：默认声明与 patch 行已移除，仅保留 no-op tombstone；旧 profile 配置不迁移、不读取、不删除，也不再包装、冷却或吞掉压缩请求。旧进程污染的热恢复不作保证。
- 新 `omnisurge-compaction-budget` 行默认关闭，只对版本指纹匹配的官方摘要方法做一次委派；压力、手动、切模、溢出与提交仍由官方拥有。
- 普通使用只需在官方插件页启停，不必调参数。可从「内置插件配置」的摘要预算详情展开高级选项：`checkpointTokens`（默认2048，完整检查点上限，含保守frame）、`safetyTokens`（1024）、`timeoutMs`（60000）。保存和Agent更新使用同一官方设置入口；下一次调用使用新参数，在途操作保持开始时的快照。
- 完整检查点上限是唯一新增硬上限，摘要长度建议不是第二个硬限制。逐模型触发、保留配置、摘要路由及输出cap仍来自官方Basic的 `modelPolicies`；插件不暗改对话输出预留、不静默切供应商，也不接管官方选区、净缩与提交。
- 输入超窗、非完整/空/超正文预算输出会明确失败并保留旧历史，不截断摘要、不返回null假成功；取消/超时是协作式，等待供应商settle后才结束，不遗留后台提交。
- 隔离验证覆盖实际安装包、官方SDK、设置保存与生命周期，不代表生产安装或真实供应商摘要质量已验。单大尾节点可能仍无法把压力降到阈值以下；本批不宣称SWE2整体问题已修复。具体通过项、失败与受控未闭合项以对应版本验收记录为准。

## 凭据与隐私

- 所有密钥只保存为官方凭据服务引用，不写入 README、日志或普通配置。
- 文档解析、手写识别和联网搜索会把相应内容发送到你选择的供应商；请按数据敏感级别决定是否启用。
- 不会自动跨供应商回退，也不会自动把某个 provider 设为全局默认。

## 兼容性与更新

- 加载范围：`>=0.2.0-rc.2 <1.0.0`
- 当前已验证：`0.2.2-rc.5`
- 其他 the agent harness 版本可以加载，但更新卡可能提示未验证；请先查看套件更新说明。

本 README 面向使用者说明当前能力，不代替具体的设置页诊断和验收记录。
