# 万物生腾套件组（Omnisurge Suite）

面向 DeepSeek Harness 的实用扩展套件。一次安装，按需在官方插件页或侧栏中开启使用。

## 包含能力

| 能力 | 简介 | 使用入口 |
|---|---|---|
| **联网搜索（SearXNG）** | 接入自建 SearXNG 实例，为对话提供可控联网检索 | 官方插件页 → 联网搜索设置卡 |
| **技能与 MCP 管理** | 集中管理本地技能与 MCP 服务器（支持 OAuth 登录与用途说明） | 左侧栏「技能 · MCP」面板 |
| **多模态能力** | 支持手写与扫描件识别（腾讯云已验；百度智能云接入待验证）与 PDF/图片文档解析（MinerU / PaddleOCR 接入已验，质量与配额未认证） | 官方插件页 → 多模态能力设置卡 |
| **Agent Teams 与环境** | 新会话默认团队模式、DeepSeek Flash 极限模式与全局环境笔记 | 官方插件页 → 对应设置卡 |
| **思考强度滑块** | 在对话输入框内快捷切换模型与思考强度档位 | 对话输入框左下角模型选择菜单 |
| **摘要压缩预算（可选）** | 为长对话自动摘要附加正文预算上限，默认关闭 | 官方插件页开启对应开关 |

## 上手说明

1. 在官方插件页按需开启对应开关（部分能力默认关闭，不会未经确认自动开启）。
2. 如需使用外部服务商（如联网搜索、手写识别、文档解析），在对应设置卡中填写凭据并测试连通即可。
3. 有新版本时，可直接在下方「套件更新」卡点击检查并安装；安装后退出并重新打开应用生效。

## 凭据与隐私

- 所有密钥均由**系统凭据管理**保存，不写入普通配置文件或日志，保存后页面不再回显明文。
- 仅在你主动开启对应能力时，才会将内容发送至你选择的服务商；套件不会静默切换服务商或覆盖你的默认搜索来源。

## 兼容性与支持

- 兼容加载范围：`>=0.2.0-rc.2 <1.0.0`（当前已验证版本：`0.2.2-rc.5` / macOS）。
- **真实供应商效果与 OCR/文档解析原生 G5 仍有未验项**（百度 IAM 当前拒绝）；完整平台与服务商支持边界见 [支持矩阵](../../docs/guides/support-matrix.md)。
